# CIRCINUS — cinematic intro

Three.js + React: процедурный мир, десять видеоэкранов, взрыв и появление эмблемы. Движение камеры и логотипа задаётся таймлайном, а не мышью. Формат кадра — 16:9, длительность — 51,5 с.

## Просмотр

Нужны Node.js и современный браузер с WebGL и поддержкой MP4/H.264.

```sh
npm ci
npm run dev
```

Видео лежат отдельно от кода в `public/video/01.mp4` … `10.mp4` и не хранятся в Git. Если в новом клоне файлов нет, скачайте их из [папки Google Drive](https://drive.google.com/drive/folders/1bXKZtdz1PGetHGCwTZ_ypulauQbocp_z) и переименуйте согласно таблице. Исходники не меняются в Drive. `npm run build` копирует локальную папку видео в `dist/video/`; её нужно развернуть вместе с `dist/index.html`.

Клипы вписаны в горизонтальные экраны без растягивания. Каждый начинается за 0,95 с до визита камеры и после окончания удерживает последний кадр. Ролик воспроизводится без звука; вступительных надписей нет, финальные название и подпись сохранены. Финальная композиция дополнена шрифтами Prata и Forum и золотыми кольцами в двух противоположных углах по мотивам прототипа; в финальном плане полосы убираются, с 47,8 секунды эмблема уменьшается, буквы названия поочерёдно сжимаются и исчезают, а с 49,6 по 51-ю секунду вся композиция плавно уходит в чёрный, который удерживается до конца ролика. Для просмотра предусмотрены пробел, F и шкала времени; `?t=35` фиксирует момент, `?look=logo` показывает логотип крупнее.

## Творческие настройки

Компактная кнопка с ползунками открывает плавающую панель; её можно перетащить за заголовок или перемещать стрелками, когда заголовок в фокусе. В ней можно менять название и подпись, их шрифты, цвета, размеры, интервалы и положение, видимость и размер логотипа, скорость появления и движение при уходе. Отдельно настраиваются угловые круги, свет, частицы и другие эффекты, угол и плавание камеры, яркость видео и порядок десяти роликов (при выборе ролики меняются местами). Исходные видео не редактируются и не заменяются. Камера по-прежнему движется по сценарию, мышь ею не управляет.

Изменения сразу применяются к сцене и сохраняются в локальном хранилище текущего браузера; кнопка «Сбросить» возвращает исходные значения. При запуске MP4 фиксируется снимок настроек — последующие изменения не влияют на уже идущий экспорт. Панель и элементы управления в видео не попадают. Частота и формат экспорта остаются неизменными.

## Экспорт MP4 на вашем компьютере

Откройте предпросмотр на своём компьютере в актуальном Chrome или Edge, дождитесь загрузки ролика и нажмите **«ЭКСПОРТ MP4»**. Все кадры и MP4 рассчитываются **в браузере на этом компьютере**, а не на сервере предпросмотра. Сервер только отдаёт страницу и десять исходных видео; готовый MP4 на сервер не отправляется. После завершения готовый ролик открывается во весь размер окна браузера. Его можно просмотреть, сохранить кнопкой **«СОХРАНИТЬ MP4»** или через меню видео, а затем закрыть. Для настоящего полноэкранного режима есть отдельная кнопка ⛶ (если браузер разрешает). После закрытия просмотра файл остаётся доступен через **«ОТКРЫТЬ ВИДЕО»** и **«СКАЧАТЬ MP4»**, пока страница не закрыта и не запущен новый экспорт.

Экспорт: 1920×1080, 30 fps, 51,5 с, 1545 кадров, без звука и интерфейса. Временная вкладка сцены скрыта и работает в том же браузере. Кадры вычисляются последовательно на времени `номер / 30`, каждый передаётся кодировщику с ожиданием освобождения очереди; сохранение доступно только после успешной сборки и проверки числа кадров. Это не запись в реальном времени: медленный рендер не пропускает кадры. Можно отменить экспорт. **Не закрывайте и по возможности не сворачивайте вкладку** до завершения: при закрытии текущая работа и несохранённый MP4 теряются.

Нужны HTTPS (или localhost), WebGL, WebCodecs и поддержка кодирования H.264. Поддержку GPU определяет браузер и драйвер: включите аппаратное ускорение в Chrome/Edge и проверьте `chrome://gpu` / `edge://gpu`; использовать GPU автоматически на всех системах гарантировать нельзя. Для файла используется оперативная память браузера, поэтому нужны свободная память и место для сохранения. Для загрузки исходных клипов требуется доступ к серверу с `public/video/01.mp4` … `10.mp4`.

Титры и полосы компонуются с WebGL непосредственно в браузере; возможны небольшие отличия текста от экранного CSS. Временные метки кадров фильма точны, но выбор кадров исходных MP4 выполняется браузерным декодером: побитовая идентичность между браузерами/GPU не гарантируется.

## Последовательность PNG (альтернативный способ)

```sh
npm ci
npx playwright install chromium
npm run export
```

Создаются `exports/frames/frame-000000.png` … `frame-001544.png`. Для проверки отрывка (верхняя граница не включается):

```sh
npm run export -- --width 1280 --height 720 --fps 30 --start 270 --end 300 --out exports/test
```

Аргументы: `--fps`, `--width`, `--height` (16:9), `--start`, `--end`, `--out`, `--pr` (масштаб WebGL 1–2), `--browser`. Папка вывода не должна содержать предыдущих `frame-*.png`. Пример ручной сборки с установленным FFmpeg:

```sh
ffmpeg -framerate 30 -start_number 0 -i exports/frames/frame-%06d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -movflags +faststart exports/circinus.mp4
```

`npm test` проверяет настройки и их снимок для экспорта, перемещение панели, просмотр и скачивание готового файла, локальный экспорт короткой тестовой сцены, 30 fps, число кадров и отмену; для тестов нужен Chromium Playwright (`npx playwright install chromium`).
